# DEWA branding scope

Use the existing DEWA name and vector mark supplied in the old project. Keep the upstream interaction layout and typography. This is a replacement of brand identity assets, not a new UI design.

- ENERGY 1 / RHYTHM 1 / MOTION 1: an internal PO/document utility; no added animation.
- Identity: the existing DEWA glyph, used for login, sidebar, splash and app icons.
- Color: white glyph on #171717 for the square app icon, with padded safe area; sufficient contrast in both themes and when the upstream UI crops it to a circle.
- Splash: dark glyph on transparent for light mode, white glyph on transparent for dark mode; preserve the original aspect ratio.
- Layout/spacing: keep upstream placement and padding; do not add navigation or controls.
- Copy: use DEWA as the product name; retain upstream license and notices, with no claims of authorship of the upstream product.

Delivery checks for this limited change: source mark preserved, generated icon dimensions verified, 17.9+:1 glyph/background contrast, no new controls/animation/layout added. Runtime checks (login/sidebar, light/dark, keyboard, mobile and existing chat/RAG) are assigned to the operator on the bastion, per the explicit request not to run Docker locally.
